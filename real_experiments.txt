================================================================================
  REAL-WORLD UR10e EXPERIMENTAL PLAN
  RIT*: Riemannian Informed Trees
================================================================================

GENERAL SETUP
-------------
- Robot: Universal Robots UR10e + Robotiq 85 gripper
- Control: ur_rtde Python driver at 500 Hz
- Coordinate frame: Robot base at origin [0,0,0]. X = forward, Y = left, Z = up
- All positions in meters, measured from the base center
- Speed limit: Max 0.5 rad/s per joint during initial tests; 1.0 rad/s for data collection
- Planners compared: RIT* (ours), BIT*, RRT*-Connect
- Trials: 20 random seeds per planner per experiment
- Obstacle geometry: Registered to the planner manually via tape-measure from
  the base center (±2 cm accuracy)

COMMON METRICS (all experiments)
1. Planning time (seconds) — wall-clock from planner start to solution
2. Success rate — fraction of seeds that find a valid path within the iteration budget
3. Total joint torque — sum of |tau(t) · delta_q(t)| read from ur_rtde at 500 Hz
4. Peak joint velocity — max ||q_dot(t)||_inf
5. Path smoothness — max jerk max ||q_triple_dot(t)||


================================================================================
  EXPERIMENT 1: TABLETOP PICK-AND-PLACE
================================================================================

PURPOSE
-------
Validate that the joint-inertia-weighted Riemannian metric produces lower-torque,
smoother paths than Euclidean planners when navigating around localized obstacles
on a table surface.

OBJECTS NEEDED
--------------
#   Object          Real Item                  Size (cm)         Position wrt Base (m)
1   Table surface   Flat wooden board / MDF     60 x 60 x 4      [0.50,  0.00,  0.40]
2   Tall box        Red wooden block            16 x 16 x 24     [0.40,  0.00,  0.55]
3   Small box       Blue wooden block           12 x 12 x 16     [0.60,  0.15,  0.50]

OBSTACLE PLACEMENT DETAIL
--------------------------
- Table surface (Object 1): A flat board elevated so the TOP surface is at
  z = 0.42 m. Use legs, risers, or stack of wood to raise it. The board spans
  x in [0.20, 0.80], y in [-0.30, 0.30]. Clamp or weigh down so it does not
  shift during robot motion.

- Tall red box (Object 2): Place on the table, centered at x=0.40, y=0.00 —
  directly in front of the robot. The box bottom sits on the table surface
  (z=0.42), so its center is at z = 0.42 + 0.12 = 0.54 m. This is the primary
  obstacle.

- Small blue box (Object 3): Place on the table at x=0.60, y=+0.15 — forward
  and to the left of the red box. Its center is at z = 0.42 + 0.08 = 0.50 m.
  This creates a secondary obstacle the arm must avoid.

PLANNER OBSTACLE DEFINITIONS
-----------------------------
  Box 1: center=[0.50, 0.00, 0.40], half_extents=[0.30, 0.30, 0.02]
  Box 2: center=[0.40, 0.00, 0.55], half_extents=[0.08, 0.08, 0.12]
  Box 3: center=[0.60, 0.15, 0.50], half_extents=[0.06, 0.06, 0.08]

START AND GOAL CONFIGURATIONS
------------------------------
         Joint Angles (deg)                    EE Position (m)         Description
Start    [0, -90, 0, -90, 0, 0]               [0.00, 0.29, 1.49]     Arm straight up — standard UR10e home pose
Goal     [68.8, -68.8, 57.3, -80.2, -90, 0]   [0.17, 0.91, 0.75]     Arm reaching to the left-forward side of the table

SETUP PROCEDURE
---------------
1. Mount UR10e on a sturdy flat surface. Mark the base center with tape.
2. Place the wooden board so its center is 50 cm forward (+X) from the base,
   elevated on supports so the top surface is at z = 0.42 m. Use a level.
3. Place the tall red block at x=0.40 m, y=0.00 m on the board (directly in front).
4. Place the small blue block at x=0.60 m, y=+0.15 m on the board (forward-left).
5. Measure all positions with a tape measure from the base center. Required
   accuracy: ±2 cm.
6. Teach the start and goal joint positions using the teach pendant. Verify EE
   positions match the table values within ±3 cm.
7. Dry-run at 5% speed to confirm no collisions.

EXPERIMENT-SPECIFIC METRICS
----------------------------
- Total energy: E = sum |tau(t) · delta_q(t)| — expect RIT* to use 20-30% less
  energy than BIT*
- Compare max torque on shoulder_lift_joint (heaviest link, 13.05 kg)


================================================================================
  EXPERIMENT 2: SHELF REACH-IN
================================================================================

PURPOSE
-------
Validate that the spatially-varying metric field improves planning in constrained
narrow-passage environments. The metric should inflate near shelf walls, biasing
samples toward the passage center and improving clearance.

OBJECTS NEEDED
--------------
#   Component       Real Item          Size (cm)         Position wrt Base (m)
1   Back wall       Plywood sheet      4 x 70 x 60      [1.22,  0.00,  0.60]
2   Top shelf       Plywood sheet      38 x 70 x 4      [1.05,  0.00,  0.90]
3   Bottom shelf    Plywood sheet      38 x 70 x 4      [1.05,  0.00,  0.30]
4   Left wall       Plywood sheet      38 x 4 x 60      [1.05, +0.35,  0.60]
5   Right wall      Plywood sheet      38 x 4 x 60      [1.05, -0.35,  0.60]

Alternatively, use a real open-front bookshelf with matching interior dimensions.

OBSTACLE PLACEMENT DETAIL
--------------------------
Option A — Build from plywood:
- Assemble a 5-sided open-front box. The front opening faces the robot.
- Interior dimensions: 36 cm deep (X), 70 cm wide (Y), 60 cm tall (Z).
- Position the shelf so the front edge is at x = 0.86 m and the back wall
  at x = 1.24 m from the robot base.
- The opening center is at y = 0.00 m (directly in front) and z = 0.60 m
  (mid-height).
- Screw or clamp the panels together. Bolt or clamp the assembly to the
  floor/table so it cannot shift.

Option B — Use a real bookshelf/cabinet:
- Find any shelf with interior dims >= 35 cm deep x 65 cm wide x 55 cm tall.
- Position with front opening facing the robot, front edge at x ≈ 0.86 m.
  Adjust planner parameters to match actual dimensions.

PLANNER OBSTACLE DEFINITIONS
-----------------------------
  Back wall:    center=[1.22, 0.00, 0.60], half=[0.02, 0.35, 0.30]
  Top shelf:    center=[1.05, 0.00, 0.90], half=[0.19, 0.35, 0.02]
  Bottom shelf: center=[1.05, 0.00, 0.30], half=[0.19, 0.35, 0.02]
  Left wall:    center=[1.05, 0.35, 0.60], half=[0.19, 0.02, 0.30]
  Right wall:   center=[1.05,-0.35, 0.60], half=[0.19, 0.02, 0.30]

START AND GOAL CONFIGURATIONS
------------------------------
         Joint Angles (deg)                    EE Position (m)         Description
Start    [0, -114.6, 90, -63, -90, 0]         [0.38, 0.17, 0.86]     Arm retracted, EE above and in front of shelf opening
Goal     [0, -57.3, 57.3, -90, -90, 0]        [1.02, 0.17, 0.58]     Arm extended, EE inside the shelf at mid-height

SETUP PROCEDURE
---------------
1. Place the shelf assembly 1.05 m in front of the robot base (center of shelf
   body). Front opening faces robot.
2. Verify the shelf is level and stable. Bolt or clamp to floor.
3. The shelf opening center should be at y = 0.00 m and z = 0.60 m.
4. Teach start pose: arm retracted, EE at approximately [0.38, 0.17, 0.86] —
   above the shelf opening.
5. Teach goal pose: arm extended into the shelf, EE at approximately
   [1.02, 0.17, 0.58] — inside the shelf at mid-height.
6. Verify the goal EE position is at least 5 cm from any wall.
7. Dry-run at 5% speed; observe clearance around all shelf walls.

EXPERIMENT-SPECIFIC METRICS
----------------------------
- Minimum clearance: Record full EE trajectory via FK at 500 Hz. Compute the
  min distance to any shelf wall at each timestep. RIT* should maintain higher
  clearance (>3 cm) vs. BIT*.
- Contact detection: If the robot touches the shelf at any point → mark trial
  as failure.
- Number of collision checks: Log from the planner. RIT* should need fewer
  due to spatially-aware sampling.


================================================================================
  EXPERIMENT 3: OVERHEAD REACH-ACROSS
================================================================================

PURPOSE
-------
Validate that the inertia-weighted metric drives energetically efficient route
selection when the direct path is globally blocked. The planner must choose to
go over or under a hanging panel; the Riemannian metric should prefer the route
that moves lighter joints.

OBJECTS NEEDED
--------------
#   Object           Real Item                                    Size (cm)         Position wrt Base (m)
1   Hanging panel    MDF board, foam board, or cardboard           40 x 30 x 5      [0.25,  0.06,  0.68]
2   Support frame    80/20 aluminum extrusion or camera tripod     —                 Overhead, z > 1.0 m

Use foam board or cardboard for the panel for safety during testing.

OBSTACLE PLACEMENT DETAIL
--------------------------
- The hanging panel is suspended from an overhead frame using string or clamps.
  It must hang freely and NOT be supported from below.
- The panel center is at [x=0.25, y=0.06, z=0.68] m — in the middle of the
  workspace, at EE height for horizontal arm poses.
- The panel spans:
    X: from 0.05 m to 0.45 m
    Y: from -0.09 m to 0.21 m
    Z: from 0.655 m to 0.705 m
- At both start and goal poses, the EE is at z = 0.677 m — exactly at panel
  height. Therefore the straight-across joint interpolation is blocked.
- SAFETY: Use foam board or thick cardboard rather than wood or metal. If the
  robot contacts it during testing, the panel deforms harmlessly.

PLANNER OBSTACLE DEFINITION
-----------------------------
  Box: center=[0.25, 0.06, 0.68], half_extents=[0.20, 0.15, 0.025]

START AND GOAL CONFIGURATIONS
------------------------------
         Joint Angles (deg)                    EE Position (m)         Description
Start    [-68.8, -90, 90, -90, -90, 0]        [0.41, -0.58, 0.68]    Arm reaching to the right side of workspace
Goal     [68.8, -90, 90, -90, -90, 0]         [0.09,  0.71, 0.68]    Arm reaching to the left side of workspace

The only difference between start and goal is the shoulder pan joint rotating
137.6°. The direct rotation path sends the forearm and gripper straight through
the hanging panel.

SETUP PROCEDURE
---------------
1. Build or position an overhead frame above the robot. An 80/20 extrusion
   frame, a camera rig crossbar, or even a door frame works.
2. Hang the 40x30x5 cm panel from the crossbar using string or clamps. The
   panel center should be at [0.25, 0.06, 0.68] m from the robot base.
3. Verify the panel height: with the robot in a horizontal-arm pose
   (shoulder lift = -90°, elbow = 90°), the EE should be at the same z as the
   panel center (z ≈ 0.68 m).
4. Teach start pose: EE at [0.41, -0.58, 0.68] (right side). Teach goal pose:
   EE at [0.09, 0.71, 0.68] (left side).
5. VERIFICATION: Run a simple linear joint interpolation from start to goal at
   5% speed with protective stop enabled. Confirm the robot COLLIDES with the
   panel — this proves the obstacle blocks the direct path and the planner must
   find a detour.
6. Ensure the support frame itself is outside the robot's reachable workspace
   or high enough (z > 1.2 m) to not interfere.

EXPERIMENT-SPECIFIC METRICS
----------------------------
- Path choice: Record the full FK trajectory. Classify the path as "over"
  (z_max > 0.75 m along the path) or "under" (z_min < 0.60 m). RIT* should
  consistently prefer "under" because it is the lower-energy route (moves wrist
  joints more, shoulder less).
- Shoulder torque: Compare peak and total torque on shoulder_pan_joint and
  shoulder_lift_joint between planners. RIT* paths should use 20-40% less
  energy since the inertia-weighted metric penalizes heavy-joint motion.
- Path length in joint space: RIT* may produce a longer Euclidean path but a
  shorter Riemannian path — report both.
